Additional information about the FEDS algorithm can be found in [Chen et al., 2022](https://www.nature.com/articles/s41597-022-01343-0). The source code used to generate the VIIRS Modeled Fire Perimeter data product is available on the [EIS fireatlas GitHub](https://github.com/Earth-Information-System/fireatlas) page. The [Wildfire Tracking Lab GitHub project page](https://earth-information-system.github.io/fireatlas/docs/) and the [UC-I/NASA Fire Tracking Page](https://www.ess.uci.edu/~uci-nasa-firetracking/) provide links to related publications, data products, and an example notebook, [Get Fire Perimeters from an OGC API](https://nasa-impact.github.io/veda-docs/notebooks/tutorials/mapping-fires.html), that demonstrates how to subset, analyze, and visualize the FEDS output outside of FIRMS, is available on NASA's VEDA platform. Finally, the data products from the FEDS algorithm are also available via [OGC API](https://firenrt.delta-backend.com/).
